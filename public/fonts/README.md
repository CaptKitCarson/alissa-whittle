# Font sources

Unmodified WOFF2 files downloaded from the Google Fonts stylesheet used by this site on 2026-09-08. Font faces, weights, optical-size axes, styles and Unicode subsets are preserved in src/styles/fonts.css. Licenses are included for Fraunces and Inter.

Source stylesheet: https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,300..600;1,9..144,300..500&family=Inter:wght@400;450;500;600&display=swap
License sources: https://github.com/google/fonts/tree/main/ofl/fraunces and https://github.com/google/fonts/tree/main/ofl/inter
